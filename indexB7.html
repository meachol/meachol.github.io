圆环旋转动画 OC 语言实现

----------使用 CAShapeLayer + CABasicAnimation 实现圆环加载动画

一、效果预览

下面是最终实现的圆环旋转动画效果（网页模拟版）：

圆弧绕中心点匀速旋转一圈，循环播放，常用于页面加载等待场景。

二、实现思路

在 iOS 开发中，圆环旋转动画通常有两种做法：

① 使用系统自带的 UIActivityIndicatorView，简单但样式固定；

② 使用 CAShapeLayer + UIBezierPath 绘制自定义圆弧，再配合 CABasicAnimation 做旋转动画，灵活可定制。

本文采用第②种方式，分三步完成：

1. 用 UIBezierPath 画出 3/4 圆弧路径；

2. 将路径赋给 CAShapeLayer 完成绘制；

3. 添加 CABasicAnimation 对 transform.rotation.z 做无限循环旋转。

三、头文件 RingAnimationView.h

// RingAnimationView.h #import <UIKit/UIKit.h> NS_ASSUME_NONNULL_BEGIN /** 圆环旋转动画视图，支持自定义颜色、线宽和旋转速度 */ @interface RingAnimationView : UIView /** 圆弧颜色，默认蓝色 */ @property (nonatomic, strong) UIColor *ringColor; /** 线宽，默认 5.0 */ @property (nonatomic, assign) CGFloat lineWidth; /** 旋转一圈所需时间（秒），默认 1.0 */ @property (nonatomic, assign) CFTimeInterval duration; /** 开始旋转动画 */ - (void)startAnimation; /** 停止旋转动画 */ - (void)stopAnimation; @end NS_ASSUME_NONNULL_END

四、实现文件 RingAnimationView.m

// RingAnimationView.m #import "RingAnimationView.h" #import <QuartzCore/QuartzCore.h> static NSString * const kRingRotationKey = @"kRingRotationKey"; @interface RingAnimationView () @property (nonatomic, strong) CAShapeLayer *ringLayer; @end @implementation RingAnimationView // ---------------------------------------------------------------- // MARK: - 初始化 // ---------------------------------------------------------------- - (instancetype)initWithFrame:(CGRect)frame { self = [super initWithFrame:frame]; if (self) { [self _setupDefaults]; [self _setupRingLayer]; } return self; } - (instancetype)initWithCoder:(NSCoder *)coder { self = [super initWithCoder:coder]; if (self) { [self _setupDefaults]; [self _setupRingLayer]; } return self; } - (void)_setupDefaults { _ringColor = [UIColor systemBlueColor]; _lineWidth = 5.0; _duration = 1.0; self.backgroundColor = [UIColor clearColor]; } // ---------------------------------------------------------------- // MARK: - 图层搭建 // ---------------------------------------------------------------- - (void)_setupRingLayer { CAShapeLayer *ring = [CAShapeLayer layer]; ring.fillColor = [UIColor clearColor].CGColor; ring.strokeColor = _ringColor.CGColor; ring.lineWidth = _lineWidth; ring.lineCap = kCALineCapRound; ring.strokeEnd = 0.75; // 画 3/4 圆弧，留出缺口更有动感 [self.layer addSublayer:ring]; self.ringLayer = ring; } - (void)layoutSubviews { [super layoutSubviews]; // 布局改变时同步更新路径 self.ringLayer.frame = self.bounds; self.ringLayer.path = [self _ringPath].CGPath; } - (UIBezierPath *)_ringPath { CGPoint center = CGPointMake(CGRectGetMidX(self.bounds), CGRectGetMidY(self.bounds)); CGFloat radius = MIN(CGRectGetWidth(self.bounds), CGRectGetHeight(self.bounds)) / 2.0 - _lineWidth / 2.0; return [UIBezierPath bezierPathWithArcCenter:center radius:radius startAngle:0 endAngle:M_PI * 2 clockwise:YES]; } // ---------------------------------------------------------------- // MARK: - 属性变更同步到图层 // ---------------------------------------------------------------- - (void)setRingColor:(UIColor *)ringColor { _ringColor = ringColor; self.ringLayer.strokeColor = ringColor.CGColor; } - (void)setLineWidth:(CGFloat)lineWidth { _lineWidth = lineWidth; self.ringLayer.lineWidth = lineWidth; self.ringLayer.path = [self _ringPath].CGPath; } // ---------------------------------------------------------------- // MARK: - 动画控制 // ---------------------------------------------------------------- - (void)startAnimation { if ([self.ringLayer animationForKey:kRingRotationKey]) { return; // 已在动画中，避免重复添加 } CABasicAnimation *rotation = [CABasicAnimation animationWithKeyPath:@"transform.rotation.z"]; rotation.fromValue = @(0); rotation.toValue = @(M_PI * 2); rotation.duration = _duration; rotation.repeatCount = HUGE_VALF; // 无限循环 rotation.timingFunction = [CAMediaTimingFunction functionWithName:kCAMediaTimingFunctionLinear]; [self.ringLayer addAnimation:rotation forKey:kRingRotationKey]; } - (void)stopAnimation { [self.ringLayer removeAnimationForKey:kRingRotationKey]; } @end

五、使用示例（ViewController.m）

#import "ViewController.h" #import "RingAnimationView.h" @interface ViewController () @property (nonatomic, strong) RingAnimationView *ringView; @end @implementation ViewController - (void)viewDidLoad { [super viewDidLoad]; // 创建圆环视图，大小 100×100 CGRect frame = CGRectMake(0, 0, 100, 100); self.ringView = [[RingAnimationView alloc] initWithFrame:frame]; self.ringView.center = self.view.center; // 自定义样式 self.ringView.ringColor = [UIColor systemBlueColor]; self.ringView.lineWidth = 6.0; self.ringView.duration = 1.0; // 1 秒转一圈 [self.view addSubview:self.ringView]; // 开始动画 [self.ringView startAnimation]; } - (void)viewWillDisappear:(BOOL)animated { [super viewWillDisappear:animated]; [self.ringView stopAnimation]; } @end

六、关键知识点说明

CAShapeLayer.strokeEnd：控制路径描边的终止位置，范围 0~1。设为 0.75 表示画出 3/4 圆弧，视觉上形成"缺口"，旋转时更有加载感。

CABasicAnimation keyPath "transform.rotation.z"：对图层绕 Z 轴（屏幕法向轴）做旋转动画，fromValue=0，toValue=2π，即旋转一圈。

repeatCount = HUGE_VALF：设置为浮点最大值，动画将无限重复；若需停止，调用 removeAnimationForKey: 即可。

layoutSubviews 中更新路径：路径依赖视图尺寸，在 layoutSubviews 中同步更新，确保旋转自适应不同屏幕和自动布局场景。
